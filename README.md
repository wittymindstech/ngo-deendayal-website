# Deen Dyaal Sewa Bharti (दीन दयाल सेवा भारती) - Official NGO Website

A complete, professional, modern, authentic, and trustworthy NGO website for **Deen Dyaal Sewa Bharti**, Kanpur, Uttar Pradesh, India.

---

## 🏛️ About Deen Dyaal Sewa Bharti
- **Organization Name:** Deen Dyaal Sewa Bharti (दीन दयाल सेवा भारती)
- **Central Motto:** *"शिक्षा के साथ संस्कार, सेवा के साथ समाज निर्माण"*
- **Secondary Mission:** *"गरीब और जरूरतमंद परिवारों के बच्चों को शिक्षा, संस्कार और बेहतर भविष्य की दिशा देना।"*
- **Current Student Impact:** **2500+ students** receiving education, character development, discipline, and cultural exposure.
- **Location:** 731-A, Hanspuram, Awas Vikas Colony, Hamirpur Road, Kanpur, Uttar Pradesh, India.
- **Contact Numbers:** `8574778211`, `9214251359` (with direct click-to-call and WhatsApp chat integration).

## 📁 Technical Architecture
Built strictly using **HTML5**, **CSS3**, and **Vanilla JavaScript** (Zero frameworks: No React, Next.js, Vue, Bootstrap, or Tailwind).

```
ngo-deendayal-website/
├── index.html              # Main semantic HTML5 single-page structure
├── css/
│   ├── style.css           # Master stylesheet (Color tokens, typography, cards, layout, tabs, lightbox)
│   └── responsive.css      # Granular responsive styles (1280px, 1024px, 768px, 480px, 360px)
├── js/
│   ├── main.js             # Sticky nav, ScrollSpy, mobile drawer, animated counters, contact form
│   ├── gallery.js          # Interactive category filtering (Education vs Social Service)
│   └── lightbox.js         # Accessible modal lightbox (Keyboard arrow/ESC navigation, focus trapping)
├── images/                 # High-resolution genuine NGO photographs, clippings, and documents
└── README.md               # Project documentation
```

## 🌟 Core Website Sections

1. **Top Announcement Bar:** Compact contact bar with student impact highlight and quick call links.
2. **Sticky Navigation Bar:** Custom Diya/Education SVG emblem, branding, desktop links, mobile hamburger drawer, and "सहयोग करें" CTA.
3. **Hero Section:** High-contrast background overlay with authentic photo, powerful Hindi headline, and dual CTAs.
4. **Impact Statistics:** 4 animated counters displaying 2500+ students, education + sanskar, community service, and Kanpur UP.
5. **About Section:** Genuine story, core purpose highlight card (*हमारा उद्देश्य*), and 4 operational pillars.
6. **Education & Sanskar (Centerpiece):** In-depth showcase of the 2500-student initiative, cultural sanskar (Matru-Pitru Pujan, Aarti, Charan Sparsh), and 3 pillars (शिक्षा, संस्कार, व्यक्तित्व विकास).
7. **Our Social Service:** 6 comprehensive cards (शिक्षा सहायता, बाढ़ एवं आपदा राहत, स्वास्थ्य सेवा, शीतकालीन कंबल वितरण, स्वच्छता अभियान, सामुदायिक खाद्यान्न सहायता).
8. **Our Approach:** 4-step horizontal process timeline (01 पहचान, 02 सहयोग, 03 संस्कार, 04 सशक्त भविष्य).
9. **Interactive Photo Gallery:** Filterable grid with accessible lightbox for education and community activities.
10. **Newspaper Coverage:** Authentic media clippings from *Dainik Jagran*, *Amar Ujala*, *Hindustan*, *Swatantra Bharat*, *Janwani*, and *Amar Sandesh*.
11. **Transparency & Governance:** Redacted public records protecting sensitive personal identifiers, displaying Society Renewal Certificate, Form 10AC Provisional Registration, and Bye-laws.
12. **Financial Transparency:** Timeline of verified accounting statements for FY 2016–17 through 2020–21 with exact original figures and document preview triggers.
13. **Emotional Call-to-Action:** Thoughtful and respectful invitation to support without manipulative donation claims.
14. **Contact Section:** Official address, clickable phone links, WhatsApp chat triggers, and interactive contact form with instant validation.
15. **Footer:** Quick navigation, contact information, copyright notice (© 2026), and informational disclaimer.

## 🚀 Running the Project
Simply open `index.html` in any modern web browser or serve via any static file server:

```bash
# Using Python built-in server (optional):
python -m http.server 8000

# Using Node http-server (optional):
npx http-server .
```
Navigate to `http://localhost:8000` to view the website.
